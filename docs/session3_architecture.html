2. The architecture: six layers

People reach the agent through channels; every channel goes through the same server rules; the agent is one graph with a gate; its sensors read the bank's data and, through the integration layer, the bank's systems. The model sits off to the side: it writes, it never decides.

4. Why the agent is integrated this way

Twelve design decisions, each a lesson from the notebooks. Together they make an agent a bank could actually run.

An agent, not a fixed script

The path depends on the file: a clean file stops after six steps; a file with exceptions quotes the policy and drafts tickets. A fixed workflow cannot adapt; an agent with a goal and a planner can.

04b stage 3
Code decides, the model writes

Ratios, rules, options and the proposal are computed in code before any model is called. The model only writes the note, and code overwrites any proposal it writes. The worst a model can do is write a bad sentence a person reads.

04b stages 4 and 5
A person at the gate, outside the agent

Policy 7.3: only the Head of Credit approves an exception. The graph pauses with interrupt(); the server checks authority before resuming, and the gate checks again.

04b stage 8, server sign()
Check its own facts

A scanned statement was misread. Accounting that must always be true catches impossible figures and sends the file to a person instead of judging wrong numbers.

04b stage 2b
Learn only what a person reviews

The agent learns conditions from Amaira's decisions, keyed by trigger. It never learns thresholds or approvals.

04b stage 6
A second agent with a different sensor

The memo agent missed Session 2's leads. A reviewing agent with the case file catches them.

04b stage 7
Label every fallback

Real systems are slow, flaky and sometimes down. The review still goes ahead, and every fact says where it came from: live, replica or estimate.

05b levels 1 to 6
Never write twice

Agents retry and graphs resume. Every write carries an idempotency key (application plus rule), so a retry files nothing new.

05b level 7
Least privilege through MCP

The Jira server offers three tools: create, get, search. The agent cannot close, assign or delete.

05b level 7
One gate, many channels

The workbench, the command line and Slack all lead to the same authority check. Every new channel is a new door.

05b level 8
Rules on the server, not the screen

Region and authority are checked on every request. Hiding a button is not security; refusing the request is.

the workbench
A record of everything

Who did what and when, for every review, refusal, decision, ticket and notification.
